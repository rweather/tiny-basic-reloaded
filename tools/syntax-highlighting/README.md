Syntax highlighting for Tiny BASIC IL
=====================================

This directory contains files for adding syntax highlighting for
Tiny BASIC IL to editors.

## VIM

1. Copy `tiny-basic-il.vim` to the directory `$HOME/.vim/syntax`.
2. Copy `tiny-basic-il-detect.vim` to the directory `$HOME/.vim/ftdetect`.
3. Make sure that `:syntax enable` is on when you run VIM.

## Other editors

Contributions welcome for other editors.
